# .NET Devices

> A cross-platform .NET library for interacting with hardware devices — printers, scanners, and similar peripherals. Targets Windows, Linux, and macOS.

## Packages

- [AdaptArch.Devices](https://www.nuget.org/packages/AdaptArch.Devices): Cross-platform device abstractions for printers, scanners, and peripherals
- [AdaptArch.Devices.DependencyInjection](https://www.nuget.org/packages/AdaptArch.Devices.DependencyInjection): Dependency injection registrations for AdaptArch.Devices
- [AdaptArch.Devices.Pdfium](https://www.nuget.org/packages/AdaptArch.Devices.Pdfium): Cross-platform PDF rasterization, so a PDF prints on a printer that cannot read one
- [AdaptArch.Devices.Windows](https://www.nuget.org/packages/AdaptArch.Devices.Windows): Windows-only spooler PDF rendering through the in-box engine
