# Devices.Samples

The printer manager sample: a web page that drives the whole library, and a `job-set`
command that runs the scripted hardware tests without a browser.

[docs/samples/printer-manager.md](../../docs/samples/printer-manager.md) describes it: how to
start it, the job set format, the smoke run, how to run it against a virtual printer in a
container, the HTTP interface, and the trimmed and native AOT publish.
