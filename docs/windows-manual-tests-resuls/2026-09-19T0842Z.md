  upside down. Per PWG 5102.4 §4.3.2.8 the header only declares the bitmap
  orientation — the client must transform the pixels. `PwgRasterWriter`
  now reorders back-side pixels to the Table 9 orientation (pixel-aware,
  colour-safe); 8 new unit tests, full suite 1108 passed.
- T10 streaming visibility (implemented, hardware check pending): every

  used to be silent. Verified SharpIppNext hands the stream to HttpClient
  untouched, so the count is what left the machine. Re-run the duplex job
  and check the server log for 1035/1036 alongside the sheets.
